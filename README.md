# 尘途问仙

原创 **3D 像素修仙动作 RPG 试玩版**。五门派、一介散修，选择与机缘改变你的道路。Three.js + Vite，模型、图标与音效由代码生成。

## 启动

Node.js 20.19+ 或 22.12+。

```powershell
npm.cmd install --cache .npm-cache
npm.cmd run dev
```

打开 http://127.0.0.1:5173/。

```powershell
npm.cmd test
npm.cmd run build
```

## 试玩路线

与岑照交谈引气 → 与东边采药人交谈，选择救助或先探遗迹 → 按 N 查看五门派与散修，亲自完成入门历练 → 采药炼丹、除妖或交委托积累修为 → 按 C 主动突破至炼气三层 → 前往荒脉遗迹，挑战守卫或调查阵纹修复封印 → 决定残卷去向。

先试丹霞谷比较容易：救助采药人得到两份灵草，去村中丹炉炼一枚回春丹，再到丹霞谷交付历练并入门。

地图上的地点可点击自动寻路，西岸经木桥到达。青禾驿恢复生命与灵力，每 30 秒实际游玩时间可以刷新普通妖物和灵草。门派营地委托可重复获取修为与灵石。离开当前道路需降低原道路声望 20，保留已学功法，完成原营地委托可恢复声望。非当前道路的功法灵力消耗增加 25%。

## 操作

| 操作            | 按键                               |
| --------------- | ---------------------------------- |
| 移动            | WASD / 方向键                      |
| 普通攻击        | J / 右键；点击敌人会接近并连续攻击 |
| 当前功法        | K                                  |
| 闪避            | 空格 / Shift                       |
| 互动            | E / Enter                          |
| 回春丹          | Q                                  |
| 行囊 / 地图     | I / M                              |
| 修炼 / 门派     | C / N                              |
| 暂停 / 关闭窗口 | Esc                                |
| 窗口选择        | Tab 移动焦点，Enter 确认           |

左键点地自动寻路；触屏有摇杆和动作按钮。左下角显示接收的按键与动作。

## 技术与存档

- `src/content.js`：门派、功法、地点、妖物、机缘与结局伏笔。
- `src/state.js`：成长、选择、资源、门派关系和存档验证。
- `src/main.js`：战斗、功法效果、任务交互、界面与输入。
- `src/world.js` / `src/navigation.js`：64×64 场景、模型、碰撞及寻路。
- `src/controls.js`：统一按键识别与即时动作分发。
- `tests/`：六条道路的剧情组合、成长循环、存档与地图可达性测试。

每五秒及重要进展自动保存，可在设置中手动保存。修仙使用 `dust-path-save-v1`，旧版 `moss-ember-save-v1` 保留。继续游玩应使用相同浏览器与地址。
